3. Mods

Modrinth (le plus simple) : écris le nom du mod dans l'adresse de sa page (modrinth.com/mod/cobblemon → « cobblemon »). Laisse la version vide pour toujours prendre la dernière.
Lien (URL) : un lien de téléchargement direct d'un fichier .jar (ex. un jar de tes Releases GitHub). Pour CurseForge, copie le lien du bouton Download et écris le nom du fichier .jar.
À mettre aussi sur le serveur
Ces mods doivent être dans le dossier mods de ton serveur (le launcher ne s'en occupe que pour les joueurs) :

    4. Publier

    1. Clique sur Copier le résultat.
    2. Ouvre la page de modification sur GitHub (connecte-toi si besoin).
    3. Dans la grande zone, fais Ctrl+A puis Ctrl+V pour tout remplacer.
    4. Clique sur Commit changes (deux fois). C'est fini : les joueurs reçoivent la nouvelle liste.
